rayslash v0.2.1 delivers the measured performance work and simplifies the
supported installation path.

Highlights:

- Faster startup, resident toggles, local results, module routing, actions, and repeated module execution.
- One self-contained rayslash RPM per architecture, with the verified module host embedded.
- Clean public RPM filenames without exposing Fedora package-release metadata.
- Consistent Calculator, Currency, Time, and Timers vector icons in Settings and results.
- Updated optimized official modules and a module host with persistent Wasmtime caching and pooled HTTP connections.
- User-local launchers prefer their matching user-local module host instead of an older system copy.

Optional modules remain uninstalled until selected in Settings. Every release
download is covered by the single `SHA256SUMS` manifest.

See the [installation guide](https://github.com/rslauncher/rayslash/blob/v0.2.1/docs/INSTALL.md)
for format-specific installation and shortcut instructions.
